# Molave---Distance-calculator
Guide for Distance calculator

## Description
```text
This program enables you to calculate the distance between 2 points.
Coordinates must be inputted and any coordinates will work
```
## How to Run
```text
-You can use any IDE as long as it has the properties that can run this code such as libraries.
-The IDE must also have the coding language Python in order for the code to work 
-Run the program
-Enter the required data
```
## Input Needed
```text
Inputs needed are,
-x coordinate of the first point or X1
-y coordinate of the first point or Y1
-x coordinate of the second point or X2
-y coordinate of the second point or Y2
```

## Sample Output
```text

Enter x coordinate of first point = 2
Enter y coordinate of first point = 3
Enter x coordinate of second point = 5
Enter y coordinate of second point = 6
The distance between the first point and the second point is, 4.2426406871193
```
